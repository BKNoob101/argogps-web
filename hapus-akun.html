Penghapusan Akun & Data

Terakhir diperbarui: 30 Agustus 2026

ArgoGPS tidak memerlukan akun untuk digunakan. Seluruh data Anda (riwayat perjalanan, tarif, tema, dan preferensi) tersimpan lokal di perangkat Anda.

Ringkas: karena tidak ada akun dan tidak ada data di server, "penghapusan akun" berarti menghapus data aplikasi di perangkat Anda.

Cara menghapus data di perangkat (Android)

  1. Buka Pengaturan HP Anda.
  2. Masuk ke Aplikasi (Apps / Application Manager).
  3. Cari dan pilih ArgoGPS.
  4. Pilih Penyimpanan → Hapus Data (Clear Storage / Clear Data).
  5. Atau cukup Uninstall aplikasi — seluruh data ikut terhapus.

Setelah data dihapus, semua riwayat, tarif kustom, dan preferensi tidak dapat dipulihkan.

Jika Anda ingin meminta penghapusan manual / verifikasi

Karena tidak ada data yang kami simpan atas nama Anda di server kami, tidak ada proses penghapusan akun dari sisi server. Jika Anda sebelumnya melakukan pembelian Premium melalui Google Play, pembatalan/langganan dikelola lewat Google Play, dan data transaksi dikelola oleh Google sesuai kebijakan mereka.

Pertanyaan lanjutan?

Hubungi kami di support@argogps.id dengan subjek "Penghapusan Data". Kami merespons maksimal 7 hari kerja.
